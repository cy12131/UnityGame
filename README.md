# UnityGame

个人 Unity 游戏开发学习与作品集项目。

## Development Environment

- Engine: Unity 6000.3.22f1
- Language: C#
- IDE: Visual Studio 2022 Community
- Platform: Windows 11

## Project Goals

- Learn Unity game client development.
- Build a complete 2D RPG prototype.
- Implement gameplay systems.
- Integrate a custom C++ game server.
- Develop a multiplayer game.

## Project Structure

- Assets: Game resources and scripts.
- Packages: Unity package dependencies.
- ProjectSettings: Unity project settings.
- Docs: Project documentation.
- Tests: Automated tests.
